# 🌡️ 창원 기온 시계열 분석

> 창원 지역 기상 데이터를 활용한 기온 변화 추이 분석 프로젝트

---

## 📌 프로젝트 개요

| 항목 | 내용 |
|---|---|
| **분석 지역** | 경상남도 창원시 |
| **분석 기간** | 2000년 ~ 2026년 |
| **데이터 출처** | 기상청 기상자료개방포털 |
| **데이터 크기** | 9,788행 |
| **분석 목적** | 장기 기온 변화 추이 및 계절 패턴 파악 |
